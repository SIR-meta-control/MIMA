# Teacher-only ET32 Model Metadata

[🏠 MIMA](../../../../README.md) · [📚 Documentation](../../../../docs/README.md)

This directory records the identity of the MLLM-distilled model used in the
reported experiment.

Artifact hashes are listed in `checksums.json`. To query an existing service,
use the repository client and pass
`--expected-model strict_student_teacher_only_et32_s32768`.

Model details are documented in the [model card](../../MODEL_CARD.md), and
service configuration is described in the
[inference guide](../../README.md#full-mima-teacher-and-mllm-distilled-services).
