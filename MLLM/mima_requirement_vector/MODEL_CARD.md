## 📐 Output contract

All methods predict the same ordered seven-dimensional vector:

| Field | Meaning | Domain |
| --- | --- | --- |
| `wp_m` | available passage width | non-negative meters |
| `hp_m` | available passage height | non-negative meters |
| `dp_m` | available depth along the traversal direction | non-negative meters |
| `hs_m` | required step/obstacle height | non-negative meters |
| `fl` | load-related task factor | `[0, 1]` |
| `fi` | inspection-related task factor | `[0, 1]` |
| `fp` | packing-related task factor | `[0, 1]` |

## 🧠 Full-MIMA teacher

The frozen teacher used an approximately 4B-parameter InternVL multimodal
backbone and exposed the common `/predict` schema. The recorded checkpoint
identifier is `checkpoint-650`; the SHA-256 of its recorded `config.json` is:

```text
e2c0abf60df5b6c4f8b70f60861ff2a371693e230978b2783a161f0fc3a09d39
```

The [teacher/student source](../teacher_student/README.md) contains the
paper-specific preprocessing, sensor-summary prompts, teacher model code and
inference service. Teacher weights are not distributed because of third-party
rights restrictions.

used for earlier model selection and offline evaluation.

| Number of trees | 32 |

## 🧠 Conventional replacement baselines

The RF, DT, and GBT rows replace only the MLLM requirement-vector generator.
Their downstream cVAE generator, energy optimizer, and controller remain
unchanged in the system-level experiment.

Unlike MLLM-distilled, these methods use the released deterministic 16-feature
adapter. The fitted bundle records 202 training samples and `random_state=42`.

| Method | Estimator |
| --- | --- |
| MLLM -> RF | `RandomForestRegressor(n_estimators=200, max_depth=8, min_samples_leaf=1)` |
| MLLM -> DT | `DecisionTreeRegressor(max_depth=6, min_samples_leaf=1)` |
| MLLM -> GBT | seven-output wrapper around `GradientBoostingRegressor(n_estimators=100, learning_rate=0.05, max_depth=2)` |

Environmental outputs are clipped to non-negative values and task-factor
outputs are clipped to `[0, 1]` after prediction. The weight hashes are stored
with the files under `models/baselines/`.
