# models

## Overview

`models` contains robot model assets used by the project:

- A ROS1 description package: `crimson_stand_legInit_forSimOnly` (`models/crimson/urdf`)
- MuJoCo scene/model files used by simulation modules (`models/crimson/mjcf`)

This module is mainly for robot description, visualization, and simulation asset loading. It does not implement custom control/algorithm nodes.
