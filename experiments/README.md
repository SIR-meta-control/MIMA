# Experiments

Paper-specific experiment and reconstruction modules are maintained here.

- [`system_level_ablation/`](system_level_ablation/README.md): seven-method
  full-chain ablation protocol, data-bundle interface, command-ready timing
  definition, and deterministic reconstruction of the reported table. The
  row-level records and sensor evaluation set are distributed separately.
- [`module_level_ablation/`](module_level_ablation/README.md): cVAE, MLP, and
  Scale GNN component ablations, selected checkpoints, archived metrics, and
  evaluation scripts. Large training and evaluation data are distributed
  separately.
